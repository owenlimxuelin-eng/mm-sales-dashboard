Operational Handbook & Technical Reference Guide

Standard operating procedure for managing WhatsApp broadcasts, intent handover, and community acknowledgments.

Required Column Headers: Your CSV file must contain exact headers: name, phone_number.

Phone Format Guidelines: Meta Cloud API accepts numbers starting with country code without plus signs or spaces.

  • Singapore Example: 6585791271
  • Malaysia Example: 60123456789
  • Auto-Cleaning: Our dashboard automatically strips spaces, dashes, and leading plus signs upon import.

1. Open **Tab 1 (Outreach Launcher)**.

2. Enter a unique **Campaign Identifier** (e.g. Nov2026_Batch01).

3. Customize the **Initial Broadcast Script**, using {{name}} placeholders.

4. Upload your CSV, inspect rows in the inspection table, and click **🚀 Launch Campaign Now**.

🎯 Stage 3: Ready for Group: AI monitors conversation intent. When the prospect asks for the WhatsApp group link or confirms readiness to join, the AI flags the lead as Stage 3 and notifies human staff to send the private invite link.

✅ Acknowledge Joined Community: After staff sends the group link and confirms the user has joined the WhatsApp group, click **"✅ Acknowledge Joined Community"** in the dashboard.

  • Updates lead stage to **Stage 4: Joined Community**.
  • Logs exact Date & Time (e.g., Joined Oct 26, 2026, 17:27).
  • Locks AI automation permanently for this user so they are not sent redundant automated texts.

🤝 Human Takeover: Click this on any lead row when staff needs to intervene manually. AI responses freeze immediately.

🤖 AI Takeover: When staff finishes chatting, click "AI Takeover". The AI scans all messages sent during human takeover to resume automated conversation smoothly.

Railway PostgreSQL Migration Script

Run this query in Railway PostgreSQL to support Stage 3 & Stage 4 Community Tracking

Copy and run this SQL inside Railway PostgreSQL Query tab:

-- Add Community Onboarding columns to prospects table
ALTER TABLE prospects 
ADD COLUMN IF NOT EXISTS joined_community BOOLEAN DEFAULT FALSE,
ADD COLUMN IF NOT EXISTS joined_community_at TIMESTAMP,
ADD COLUMN IF NOT EXISTS acknowledged_by VARCHAR(100),
ADD COLUMN IF NOT EXISTS interest_level VARCHAR(50) DEFAULT 'Unknown';

-- Create Stage Index for fast querying
CREATE INDEX IF NOT EXISTS idx_prospects_stage ON prospects(current_stage);

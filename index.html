Postgres + n8n + WhatsApp + OpenAI - Zero to Production

1. Neon Postgres - Fresh

Run schema.sql. Connect with pooling OFF (critical). Host without -pooler-, no channel_binding. Test SELECT * FROM leads;

2. n8n Cloud - 5 Workflows

• GET /get-crm-data → SELECT * FROM leads
• POST /add-lead → INSERT
• POST /update-lead-stage → UPDATE
• POST /ai-chat → OpenAI gpt-4o-mini + Brain 1/2 prompts
• POST /whatsapp-incoming → Receive WA messages → AI reply
• POST /whatsapp-send → Send WA templates

3. OpenAI API

platform.openai.com → API Keys → Create → n8n Credentials → OpenAI → Paste. Used in ai-chat workflow. Cost: gpt-4o-mini $0.15/1M tokens.

4. WhatsApp Business API

developers.facebook.com → Create App → WhatsApp → Get Phone Number ID + Access Token. n8n Credentials → WhatsApp Business. Webhook: https://lhy05.app.n8n.cloud/webhook/whatsapp-incoming + Verify Token you set.

5. GitHub Pages - Deploy
